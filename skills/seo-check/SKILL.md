description: Check every public page's title, description and headings before publishing.
disable-model-invocation: true
---

For every public page:

1. List the title tag and its length. Flag any over 60 characters or duplicated.
2. List the meta description and its length. Flag any missing or over 155 characters.
3. Check there's exactly one h1 and it says what the page is about.
4. Check every image has alt text.
5. Show the results as a table, then the 3 most important fixes. Don't edit anything until I say so.
