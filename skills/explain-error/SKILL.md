---
name: explain-error
description: Explain an error message in plain English before fixing it. Use when I paste an error, a stack trace, or say something is broken or red.
---

When I share an error:

1. Say in one or two plain sentences what the error means. No jargon.
2. Point to the file and line most likely causing it, and say why.
3. Suggest the smallest fix. Don't change any code until I say go.
4. If you're not sure, say so and tell me what to check first.
