---
name: ui-style
description: Design rules for this app's pages and components. Use when creating or editing UI.
paths: src/components/**, src/app/**
---

- Reuse the existing Button, Card and Input components before making new ones.
- Use the Tailwind classes already in the project. No inline styles.
- Mobile first: every layout must work at 375px wide.
- Buttons and links need a visible focus style.
- Keep the color palette to the brand colors in tailwind.config.
