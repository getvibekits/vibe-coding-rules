# Project overview
A one-page landing site for a local dog-grooming business. Plain HTML, Tailwind via CDN, no build step.

## Rules
- Keep everything in index.html and styles.css. Don't add a framework.
- Mobile first: every section must look right at 375px wide.
- Every image needs alt text. Use one h1 on the page.
- The contact form posts to the existing form service URL. Don't change it.
- Keep the page fast: no new scripts or fonts without asking.
